BHAVANA & SURYA NITHISH - WEDDING INVITATION

HOW TO RUN
1. Extract the ZIP.
2. Open index.html in a browser. For best results use VS Code + Live Server.
3. Internet is required for Bootstrap, Google Fonts and the remote Unsplash placeholder images.

WHAT TO EDIT
- Names, invitation wording, event details, venue, image URLs: index.html
- Colours, typography, layout and responsive styling: css/style.css
- Wedding countdown date/time and WhatsApp RSVP number: js/script.js
- RSVP WhatsApp number: replace 91XXXXXXXXXX with the full country code + number, digits only.

IMAGES
All photos are online Unsplash placeholders. Replace their URLs in index.html and the CSS background-image declarations with your own photos.

NOTE
The reference URL did not expose readable page content to the browsing tool, so this is a complete wedding invitation starter inspired by an elegant Indian wedding aesthetic, not a pixel-verified exact reproduction. Send screenshots of the reference page (desktop and mobile) if you want the layout matched section by section.
